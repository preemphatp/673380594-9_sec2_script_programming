## ส่วนที่ 1: Benefits of Modularity

จากที่เรียนเรื่อง Functions & Modules ในสัปดาห์นี้ ดิฉันมองว่า modular programming
ช่วยได้ในสถานการณ์ต่อไปนี้:

**1. โปรเจกต์ขนาดใหญ่**
ตอนทำ Mini Project "ระบบแจ้งเตือนเครื่องซักผ้าร้านหยอดเหรียญ" ของกลุ่มดิฉัน เขียน
โค้ดทุกอย่างไว้ในไฟล์เดียวยาวๆทำให้อ่านและแก้ยากมาก การแยกเป็นฟังก์ชัน/โมดูลทำให้
จัดการแต่ละส่วนได้เป็นอิสระจากกัน

**2. การทำงานเป็นทีม**
กลุ่มดิฉันแบ่งหน้าที่กันชัดเจน คือ พิชยา เป็น Planner, มุกดา เป็น Debugger และดิฉันเป็น
Coder ถ้าโค้ดไม่ถูกแบ่งเป็นฟังก์ชัน/โมดูลที่ชัดเจน การที่แต่ละคนแก้คนละส่วนพร้อมกัน
จะเกิด conflict บ่อยมาก

**3. Debugging**
ในบทบาท Coder ของดิฉัน การที่โค้ดถูกแยกเป็นฟังก์ชันย่อยๆ ตั้งแต่ตอนเขียน ช่วยให้มุกดา
ซึ่งรับหน้าที่ Debugger หาจุดที่บั๊กเกิดขึ้นได้เร็วขึ้นมาก เพราะรู้ว่าปัญหาน่าจะอยู่ในฟังก์ชันไหน
แทนที่จะต้องไล่อ่านทั้งไฟล์

**4. Code Testing**
สามารถทดสอบแต่ละฟังก์ชันแยกกันได้ เช่นใน Lab 6.2 ดิฉันทดสอบ `is_prime()` กับ
หลายค่า เช่น (1,3,4,5,11) ได้โดยไม่ต้องรันโปรแกรมทั้งหมด

## ส่วนที่ 2: Standard Library Exploration

ดิฉันเข้าไปสำรวจที่ [docs.python.org/3/library](https://docs.python.org/3/library/)
และเลือกโมดูลที่สนใจมา 3 โมดูล ดังนี้:

### 1. `datetime`
ดิฉันคิดว่าโมดูลนี้เอาไปใช้กับ Mini Project ของกลุ่มดิฉันได้ เพราะระบบแจ้งเตือน
เครื่องซักผ้าต้องคำนวณเวลาที่เหลือก่อนซักเสร็จ

```python
from datetime import datetime, timedelta

start_time = datetime.now()
wash_duration = timedelta(minutes=40)
finish_time = start_time + wash_duration
print(f"ซักเสร็จเวลา: {finish_time.strftime('%H:%M')}")
```

### 2. `os`
ใช้เช็คว่าไฟล์ในโปรเจกต์มีอยู่จริงไหมก่อนเปิดอ่าน มีประโยชน์ตอนดิฉันแก้ปัญหา
เรื่อง path/folder ตอนทำ Mini Project เช่นกัน

```python
import os

if os.path.exists("My_utils.py"):
    print("พบไฟล์ My_utils.py แล้ว")
else:
    print("ไม่พบไฟล์ ต้องสร้างใหม่")
```

### 3. `collections`
สนใจ `Counter` เพราะใช้นับความถี่ของข้อมูลได้ง่าย เช่น ถ้าจะนับว่าช่วงเวลาไหน
มีคนมาใช้เครื่องซักผ้าบ่อยที่สุด

```python
from collections import Counter

usage_hours = [9, 10, 9, 18, 19, 9, 18]
count = Counter(usage_hours)
print(count.most_common(1))  # ชั่วโมงที่มีคนใช้บ่อยที่สุด
```
