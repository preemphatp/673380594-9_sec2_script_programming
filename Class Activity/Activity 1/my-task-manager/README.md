
# รายละเอียดการทำงานและฟังก์ชั่นของ Task Manager CLI

แอปพลิเคชันบริหารจัดการงานผ่านบรรทัดคำสั่ง (CLI) ที่ช่วยบันทึกและติดตามสถานะงานอย่างเป็นระบบ พร้อมระบบบันทึกข้อมูลถาวรลงไฟล์ JSON

---

## ความสามารถของโปรแกรม (Program Capabilities)

* **เพิ่มรายการงาน (Add Task)**: บันทึกงานใหม่พร้อมระบบรันเลข ID ให้อัตโนมัติ
* **แสดงรายการงาน (List Tasks)**: ดึงข้อมูลงานทั้งหมดมาแสดงผล พร้อมระบุสถานะว่าอยู่ในช่วงรอดำเนินการ (`Pending`) หรือทำเสร็จแล้ว (`Completed`)
* **อัปเดตสถานะงาน (Complete Task)**: เปลี่ยนสถานะงานตาม ID ให้เป็นเสร็จสิ้น
* **ลบรายการงาน (Delete Task)**: นำรายการงานที่ไม่ต้องการออกจากระบบตาม ID
* **บันทึกข้อมูลถาวร (Data Persistence)**: บันทึกข้อมูลลงไฟล์ `data/tasks.json` อัตโนมัติ ทำให้ข้อมูลไม่สูญหายเมื่อปิดโปรแกรม
* **ระบบป้องกันโปรแกรมค้าง (Error Handling)**: ดักจับข้อผิดพลาดกรณีผู้ใช้กรอกข้อมูลผิดประเภท (เช่น ใส่ตัวอักษรในช่องที่ต้องใส่ตัวเลข ID)

---

## ฟังก์ชั่นในแต่ละโมดูล (Function Breakdown)

### 1. โมดูลจัดการไฟล์ข้อมูล (`src/task_data.py`)

* **`load_tasks()`**
  * **หน้าที่**: อ่านข้อมูลงานจากไฟล์ `data/tasks.json`
  * **การทำงาน**: เช็กว่ามีไฟล์อยู่หรือไม่ หากยังไม่มีจะสร้างไดเรกทอรี `data/` และคืนค่าลิสต์ว่าง `[]` หากไฟล์เสียหายจะดักจับ `JSONDecodeError` เพื่อป้องกันโปรแกรมล่ม

* **`save_tasks(tasks)`**
  * **หน้าที่**: บันทึกข้อมูลงานลงไฟล์
  * **การทำงาน**: รับค่าลิสต์ของงานเข้ามา แล้วแปลงเป็นรูปแบบ JSON จัดย่อหน้าให้จัดเก็บอ่านง่าย (`indent=4`) ลงในไฟล์ `data/tasks.json`

---

### 2. โมดูลการทำงานหลัก (`src/task_logic.py`)

* **`get_next_task_id(tasks)`**
  * **หน้าที่**: คำนวณหาเลข ID สำหรับงานใหม่
  * **การทำงาน**: ค้นหาค่า ID ที่มากที่สุดในรายการงานปัจจุบันแล้วบวกเพิ่มอีก 1 แต่ถ้ายังไม่มีงานในระบบจะเริ่มนับที่ ID 1

* **`add_task(tasks, description)`**
  * **หน้าที่**: เพิ่มงานใหม่เข้าสู่ระบบ
  * **การทำงาน**: เรียกใช้ `get_next_task_id()` เพื่อสร้าง ID แล้วสร้าง Dictionary งานใหม่โดยตั้งสถานะเริ่มต้น `completed: False` จากนั้นนำไปต่อท้ายลิสต์

* **`list_tasks(tasks)`**
  * **หน้าที่**: แสดงรายการงานทั้งหมด
  * **การทำงาน**: วนลูปอ่านข้อมูลในลิสต์งาน หากงานนั้นมีค่า `completed` เป็น `True` จะแสดงสถานะเป็น "Completed" หากเป็น `False` จะแสดง "Pending"

* **`complete_task(tasks, task_id)`**
  * **หน้าที่**: เปลี่ยนสถานะงานเป็นทำเสร็จแล้ว
  * **การทำงาน**: ค้นหางานตาม `task_id` เมื่อเจอจะปรับค่า `completed` ให้เป็น `True` หากไม่พบจะแสดงข้อความแจ้งเตือน

* **`delete_task(tasks, task_id)`**
  * **หน้าที่**: ลบรายการงานออกจากระบบ
  * **การทำงาน**: สร้างลิสต์ใหม่โดยกรองเอาเฉพาะงานที่มี ID ไม่ตรงกับ `task_id` ออกไป

---

### 3. โมดูลหลักและส่วนโต้ตอบผู้ใช้ (`main.py`)

* **`display_menu()`**
  * **หน้าที่**: พิมพ์ข้อความแสดงเมนูตัวเลือก (1-5) บนหน้าจอ CLI

* **`main()`**
  * **หน้าที่**: ควบคุมการทำงานหลักทั้งหมดของโปรแกรม
  * **การทำงาน**: 
    1. เรียกใช้ `task_data.load_tasks()` เพื่อดึงข้อมูลเดิมขึ้นมา
    2. ทำงานผ่านลูป `while True` เพื่อรับอินพุตจากผู้ใช้
    3. แยกเงื่อนไข (`if/elif/else`) เพื่อเรียกใช้ฟังก์ชั่นใน `task_logic.py` ให้ตรงกับเมนูที่เลือก
    4. ครอบด้วยบล็อก `try-except ValueError` ป้องกันการป้อนข้อมูลผิดประเภท
    5. เมื่อกดเมนู 5 โปรแกรมจะเรียก `task_data.save_tasks()` เพื่อเซฟข้อมูลก่อนปิดตัวลง
