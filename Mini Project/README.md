# Mini Project: ระบบแจ้งเตือนเครื่องซักผ้าร้านหยอดเหรียญ

**Repository:** https://github.com/preemphatp/Mini_Project

- **ทำร่วมกับ:** กลุ่ม 3, Sec.2 (หน้าที่ของฉัน: Coder)
- **เนื้อหาที่ใช้:** dictionary, set, frozenset, tuple, control flow, defensive programming
- **ไฟล์หลัก:** `Sourcecode.ipynb`, `CHANGELOG.md`, `LEARNINGLOG.md`
