# Final Project: Virtual Pet Companion

**Repository:** https://github.com/144P75/script_project
**Web:** https://virtual-pet-companion.onrender.com/

เกมเลี้ยงสัตว์เสมือนจริง เล่นได้ทั้งบน CLI และหน้าเว็บ เขียนด้วย Python แบบ OOP และแบ่งเป็นโมดูล

- **ฟีเจอร์หลัก:** สถานะลดลงตามเวลาจริง, เซฟข้อมูลเป็น JSON, เชื่อม Cat Facts API, คุยกับสัตว์เลี้ยงผ่าน AI
- **DevOps:** ทดสอบอัตโนมัติด้วย GitHub Actions และ deploy บน Render
- **การทำงาน:** แบ่งเป็น sprint ดูรายละเอียดในโฟลเดอร์ `sprints/` ของ repo
